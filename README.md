# DotFiles-of-WIndows

# ❄️ Hyprlands OS | Windows Tiling Environment

A high-performance, unified Windows configuration inspired by Hyprland. Powered by AutoHotkey and Komorebi.

## 🚀 Features
* **Resolution-Independent Mouse Resize:** native feel on any display.
* **Fluid Line Selectors:** High-speed text editing logic.
* **Integrated HUD:** Custom Tokyo Night / Hyprland styled cheat sheet.
* **Native Performance:** 10ms response time auto-clicker and low-latency tiling.

## ⌨️ Quick Starts
* `Alt + O` : Reload Environment
* `Shift + \` : Toggle Hyprlands HUD
* `Alt + F` : Toggle Floating (Auto-Centered)
* `Middle-Click Title` : Kill Window
